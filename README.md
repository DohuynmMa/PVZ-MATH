# 🧮 PVZ-Math

> 当数学遇上PVZ，会发生什么？

---

## 📝 项目简介

这是我的第二个 Unity 项目。

灵感来源于一节无聊的早八英语课——  
当时突然在想：

> 为什么数学不能和《植物大战僵尸》做成一款游戏？

于是，这个项目就诞生了。

---

## 💡 核心想法

**PVZ-Math** 尝试将“PVZ玩法”与“数学元素”结合：

- 用数学机制驱动战斗 
- 在游戏过程中引入计算或逻辑思考  
- 让原本偏枯燥的内容变得更有互动性  

虽然鄙人的数学水平不算好，但还是尽力把这个想法做成了一个可玩的原型。

---

## ⚠️ 项目现状

很遗憾，这个项目目前已经**停止更新**。

原本计划：
- 去除部分存在争议的元素  
- 打磨体验  
- 上架到 Steam  

但由于一些原因，这些计划暂时被搁置了。

---

## 🔥 一点想说的话

这个项目从想法到实现，对我来说意义很大。  
但在推进过程中，它也逐渐变得有些“冷清”。

如果你刚好对这个方向感兴趣，或者喜欢这个点子：

你可以自由地：

- 继续开发它  
- 优化玩法设计  
- 重构或扩展系统  

> 也许它还不够成熟，  
> 但它不一定要就此结束。

如果你愿意，它完全可以继续成长。

---

## 🚀 使用方式
  
下载源代码，使用 Unity `2022.3.34f1c1` 将文件夹作为项目打开。
